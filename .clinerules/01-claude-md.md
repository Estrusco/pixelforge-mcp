# Project Rules

Before doing any work in this repository, read `CLAUDE.md` in the project root in full and treat
it as the authoritative source for architecture, locked decisions, tool surface, conventions, and
workflow (including the beads `bd` task-tracking rules — do not use TodoWrite/markdown TODOs here).

`CLAUDE.md` is updated independently of this file. If it has changed since you last read it, or if
you're unsure whether your understanding of the project is current, re-read it before proceeding.
